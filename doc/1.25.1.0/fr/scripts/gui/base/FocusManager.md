# gui/base/FocusManager.lua

*[English version](../../../../scripts/gui/base/FocusManager.md)*

Source: `dataS/scripts/gui/base/FocusManager.lua` — FS25 1.25.1.0

✍ Gestionnaire de type singleton qui décide quel GuiElement de l'écran courant a le focus clavier/manette et comment le focus passe d'un élément à l'autre. Les données de focus sont conservées par écran ; les voisins viennent des attributs XML (focusId, focusChange*, focusInit, focusChangeOverride), du code, ou sont trouvés automatiquement par proximité. La navigation utilise les actions MENU_AXIS_* avec des délais de répétition, et les changements de focus ou de surbrillance jouent des sons de survol via un GuiSoundPlayer. Les constantes comme TOP/BOTTOM/LEFT/RIGHT, les délais et EPSILON sont définies hors des corps visibles (NON VÉRIFIÉ).

- **FocusManager** (l.22)
