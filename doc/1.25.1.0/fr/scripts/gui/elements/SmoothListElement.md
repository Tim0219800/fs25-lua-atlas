# gui/elements/SmoothListElement.lua

*[English version](../../../../scripts/gui/elements/SmoothListElement.md)*

Source: `dataS/scripts/gui/elements/SmoothListElement.lua` — FS25 1.25.1.0

✍ Élément de liste à défilement fluide et virtualisée (dérivé de GuiElement, avec IndexChangeSubjectMixin et PlaySampleMixin). Une source de données fournit sections, nombre d'éléments, noms de types de cellules et remplissage des cellules, tandis qu'un délégué reçoit les événements. Les cellules ListItemElement enfants sont placées dans une base de cellules, clonées à la demande, recyclées via un cache et positionnées d'après des décalages calculés : seules les lignes visibles existent. Il gère listes verticales ou horizontales, plusieurs éléments par ligne, en-têtes de section, cellules vides de remplissage, souris, tactile et manette. Plusieurs membres utilisés ici (scrollTo, setSelectedItem, setHighlightedItem, updateCellPosition, updateScrollClippers, raiseSliderUpdateEvent, update) ne figurent pas dans les parties décrites de ce fichier : leur comportement est NON VÉRIFIÉ.

- **SmoothListElement** hérite de `GuiElement` (l.33)
