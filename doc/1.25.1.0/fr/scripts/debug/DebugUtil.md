# debug/DebugUtil.lua

*[English version](../../../scripts/debug/DebugUtil.md)*

Source: `dataS/scripts/debug/DebugUtil.lua` — FS25 1.25.1.0

✍ DebugUtil est une table d'aides statiques pour le dessin de débogage en mode immédiat (lignes, repères, cercles, cubes, parallélogrammes), construit sur les fonctions moteur `drawDebugLine`, `drawDebugTriangle` et `drawDebugPoint`, avec en plus des aides pour le texte et l'affichage de tables ou de hiérarchies de noeuds. Les fonctions de dessin doivent être appelées à chaque image. Certaines fonctions de ce dump s'appuient sur des aides dont le corps n'est pas inclus (`DebugGizmo.renderAtNodeWithOffset`, `DebugUtil.setNodeEffectivelyVisible`, `DebugUtil.DEFAULT_RENDERLINE_SCALAR`).

- **DebugUtil** (l.8)
